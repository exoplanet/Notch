# How to Find Your Tinnitus Frequency and Set a Notch for Music

This is a listening guide for shaping music. It is not a hearing test, a diagnosis, or a treatment.

## Safety first

- Work in a quiet room and use headphones.
- Keep the volume low. The test tone only needs to be loud enough to hear.
- Do not try to mask or drown out tinnitus with loud sounds.
- Stop if anything feels uncomfortable. Rest, and try again another day at a lower volume.

## Finding your tinnitus frequency

Use a pure-tone generator or a dedicated tinnitus frequency matcher. The free tool below is one option.

1. Start with a broad sweep. Play about 1,000 Hz, then 4,000 Hz, then 8,000 Hz. After each tone, note whether your tinnitus sounds higher or lower.
2. Narrow the range. If the tinnitus sits between two of those tones, try the frequencies in between. Move in smaller steps until an external tone matches the tinnitus or blends with it.
3. Check for an octave error. A tone an octave away can feel like the same pitch. Play half your candidate frequency, then double it. If one of those blends more cleanly, use that frequency instead.
4. If the two ears differ, match each ear on its own.
5. Repeat the match on a different day. Small differences are normal. An approximate match is usually enough.

Most people’s tinnitus falls between about 3,000 and 8,000 Hz. It can sit outside that range. In Notch, a center can be set from 500 Hz to 10,000 Hz.

## Notch width for music

Start with a width of ¼ to ½ octave, centered on the matched frequency. In Notch the Width control is already in octaves:

- ½ octave is **0.5**. This is the width to start with. It is more forgiving, and it is the width often used in research.
- ¼ octave is **0.25**. On the 0.1 step control, **0.2** or **0.3** is the nearest setting. A narrower notch removes less musical content.

A fractional octave scales with the center frequency, so the same Width applies to every notch. A 0.5 setting is about 350 Hz wide at 1,000 Hz and about 1,400 Hz wide at 4,000 Hz. Use that same fractional width for each notch.

## Recommended free tool

The [AudioNotch Tinnitus Frequency Matcher](https://audionotch.com/tinnitus-frequency-matcher/) is free. It walks you through the comparison with a slider, and it can also match using narrowband noise.

Set each notch’s center to your matched frequency, set Width to 0.5 octave, turn that notch on, and play music at a comfortable volume.

## Playlists

You can play more than one file. Each file passes through the notches you turned on.

- **Add tracks** adds the files you pick, in that order.
- **Add albums** adds a folder, including disc folders such as CD1 and CD2. Tracks play by disc, then track number, then file name. The disc number in the file is used when the file has one. A folder named CD1, CD 2, or Disc 1 counts as that disc. Numbered discs play first, and files in the album folder itself play after those discs. A file with no track number plays after the numbered tracks on its disc. Names are ordered so that 2 comes before 10.
- **Queue** shows files and albums together. Tap a track to play it. Drag the ⋮⋮ handle to move a file or a whole album. Swipe a row to the left to remove it. Removing the track that is playing continues with the next track.
- **Repeat** steps through Repeat off, Repeat all, and Repeat one. Off stops after the last track. All returns to the first track. One keeps the current track playing. Load starts with Repeat off.
- **Playlists**, from the menu, keeps named lists on this phone. **New playlist** takes a name, then tracks or albums, then **Create**. The **...** menu on a playlist opens Play, Add to queue, Edit, Rename, and Delete. **Edit** changes the name and the tracks. The same playlist can be added to the queue more than once. After you leave Notch, **Resume** continues the last playlist where you left off.
- A moved or deleted file is marked Unavailable and skipped. The queue counts those tracks, and the player says “Some tracks are unavailable.” A missing album track stays in its place. Put the file back in that folder and load the playlist again to play it. A moved file has a new location, so add it again. If the album folder cannot be opened, Notch keeps the saved list and marks the tracks it cannot read.
